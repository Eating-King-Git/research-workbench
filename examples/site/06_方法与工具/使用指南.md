# 通用工作台使用指南

## 开始使用
解压全部文件后运行首次安装.cmd，再运行启动工作台.cmd。默认本机端口 8767。停止工作台.cmd 只停止同目录的服务。安装与运行不需要模型账号或付费 API。

## 阅读与批注
在文献库打开虚构示例，选中正文后添加批注。保存整篇理解、疑问和阅读位置。已保存的批注可整理为讨论材料，手动复制到自己选择的 AI 对话；网页不会自动发送。

## 添加自己的内容
网页“收录论文”保存网址与元信息，但不会自动下载论文或生成阅读卡。可在 site/05_文献阅读/阅读卡 下新建 UTF-8 Markdown；在 site/05_文献阅读/文献元数据.json 中按示例填写唯一 work_id 和 card_path，再更新资料索引。新增网页条目和本地元数据不要重复收录同一网址。
其他 Markdown 可放在 site/00_阅读入口、01_工作接续、02_个人科研梳理、06_方法与工具，或直接放在 05_文献阅读。资料索引会列出这些文件。仅阅读卡子目录支持下一级 Markdown；不会扫描任意深层文件夹。PDF 和外部网页尚不支持划词批注。

## 备份与迁移
网页 JSON 导出包括个人阅读记录、批注、任务、收藏筛选和网页新增文献。它不包含 Markdown 正文、元数据或 PDF。恢复到其他电脑时需同时保留相同的 site 资料和相对路径，否则批注仍保留但可能无法定位原文。
完整备份：停止服务后复制整个文件夹；迁移到新路径后重新运行首次安装.cmd。请勿将自己的 site/07_个人记录、备份或日志混入给别人的干净模板。

## 数据位置
个人记录自动保存在 site/07_个人记录。程序在 program，离线依赖在 wheels，虚拟环境在 .venv；这些目录全部相对于解压位置，不依赖原作者电脑。实验索引和材料索引初始为空。
