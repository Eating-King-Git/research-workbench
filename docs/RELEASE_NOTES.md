## 1.3.0-beta.2 — 2026-11-24

本次为安装包文档更新，程序功能与 beta.1 相同。

- 安装包根目录新增完整的“安装与论文归档提示词.txt”，可直接随包转发。
- “先看这里.txt”和 README 增加使用说明：复制全文给能操作本机文件和命令的AI助手，并告知安装包位置。
- 流程包括安装检查、可选资料整理、常见目录/指定磁盘/明确授权后全盘扫描、去重与版本区分、保留原文件的归档和验收。
- 提示词不会自行执行；普通网页聊天未必有本机操作能力，软件不会默认扫描磁盘。

使用：完整解压 → 阅读“先看这里.txt” → 将提示词交给本地AI助手；也可继续手动运行“首次安装.cmd”和“启动工作台.cmd”。需要Windows x64和标准Python3.13 x64。
