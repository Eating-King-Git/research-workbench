# 使用指南

## 阅读、批注与讨论

在文献库打开示例阅读卡。选中正文的一句话，点击“给所选原文批注”，填写困惑并保存。看到保存时间后再离开页面。

“我的阅读记录”用于整篇理解、问题、阅读位置与下一步；“我的笔记”汇总整篇笔记和句段批注。读完点击“读完，讨论疑问”，选择问题，生成讨论材料，然后手动粘贴到自己的 AI 对话。讨论完成后，把摘录与自己的理解填回原批注，并自行确认状态。

材料包含引用、上下文、笔记以及本机文件路径；它只在本地生成，发送给外部服务由你决定。

## 加入自己的资料

网页“收录论文”可保存网址、题名、版本与关注原因；当前没有自动下载全文、OCR 或自动阅读卡生成。

要加入可批注的正文：

1. 在运行目录 `site/05_文献阅读/阅读卡/` 中新建 UTF-8 Markdown 文件。
2. 仿照 `site/05_文献阅读/文献元数据.json` 的示例，填写唯一 `work_id`、题名、网址与 `card_path`。路径相对于 `site/`，使用 `/`。
3. 在“资料与历史”点击“更新资料索引”。同一篇论文不要同时通过网页与元数据重复收录。

通用 Markdown 也可放到 `site/00_阅读入口`、`01_工作接续`、`02_个人科研梳理`、`06_方法与工具` 或 `05_文献阅读`。这些位置只扫描直接下级 `.md`，另扫描 `05_文献阅读/阅读卡/*.md`；不会递归收录整个磁盘。

修改模板 `examples/site/` 不会修改既有实例。实际使用时编辑 `site/`，模板用于干净发布。

## 备份与迁移

在“备份与恢复”下载个人记录 JSON。恢复时选择文件或粘贴完整 JSON，点击预览，检查新增与冲突条目，再导入。导入前会自动保存当前个人记录备份。

JSON 包含笔记、批注、任务、收藏筛选和网页新增文献。**不包含正文、PDF、基础元数据，也不导出旧修订历史。**

完整备份：停止工作台，复制整个目录。新电脑需标准 Python 3.13 x64，再运行首次安装；移动后不能假定旧虚拟环境可直接使用。保留 `site/` 的资料和相对路径，批注才能定位原文。原文变动时请核对版本提示。

不要把已使用的目录直接压缩后公开。开发者应使用 `tools/build_release.py`，它只读取允许清单和干净示例。

## 常见问题

- **找不到 Python：** 在命令行确认 `python --version` 是 3.13，或者 `py -3.13 --version` 可用。安装器优先尝试后者。
- **没有离线依赖：** 确认下载的是 Release 附件。源码用户先执行 `python tools/fetch_wheels.py`。
- **端口占用：** 不要终止未知进程。在 PowerShell 中设置 `$env:WORKBENCH_PORT='8877'`，然后运行启动脚本；停止脚本须在同样的设置下执行。实际地址以启动输出为准。
- **保存失败：** 先导出草稿或复制内容，重新启动并刷新连接，再保存。若出现冲突，比较新旧版本并手动合并。
- **无法下载备份：** 检查浏览器下载面板；也可打开本机 `/api/export` 保存 JSON。发布测试记录说明具体浏览器已验证的范围。
- **启动失败：** 查看 `site/07_个人记录/.runtime/service.log`。反馈前删除路径、笔记和其他私人内容。

服务仅监听 `127.0.0.1`。不提供远程身份认证，不应配置为公网或共享服务器。


## 全站批注与升级（1.3）

在站内页面选中文字，点“添加批注”并保存。右下角“批注与讨论”可搜索、按状态筛选和跨页多选。单条点“讨论这条”，多条点“讨论选中项”，复制或下载材料到AI聊天。长材料可分段准备。讨论后在“讨论记录”保存摘录，下次讨论会携带相关摘录。自己的理解和状态由本人确认。

快照包含可见文字与选区结构化文本，不包括图片和未展开内容。PDF为带页码的文字视图，公式、表格、多栏和旋转文字请对照原文件。直接file://打开的静态文件不支持保存，应通过工作台访问。

升级请先停止旧版并备份整个目录。将新版解压到新目录，把旧版site文件夹复制到新版目录，再运行首次安装。不要用示例覆盖自己的site。旧版程序不显示新类型记录，回退前请保留完整备份。
